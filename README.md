# 闪亮收藏

《以闪亮之名》素材码的本地优先收藏与管理应用。

当前已完成本地素材管理、图片处理、完整备份恢复和 PWA 安装体验。素材、标签、图片与关系数据均保存在浏览器 IndexedDB。

## 启动

```powershell
pnpm install
pnpm dev
```

## 安装到手机

- Android：使用 Chrome 打开站点，点击首页的“安装”，或在浏览器菜单选择“安装应用”。
- iPhone / iPad：使用 Safari 打开站点，点击“分享”→“添加到主屏幕”。
- 安装后可从桌面独立启动；应用外壳支持离线打开，收藏数据仍仅保存在当前设备。
- 微信、QQ 等内置浏览器可能不支持安装，请先选择“在浏览器打开”。

## 已确认的 Phase 1 数据边界

- 图片的唯一排序来源是 `Asset.imageIds`；`StoredImage` 不保存 `order`。
- 图片主数据和缩略图分离，ZIP 备份仅导出主图，恢复后重新生成缩略图。
- V1 仅支持“完整恢复”：校验后替换当前业务数据；不实现合并导入。
- IndexedDB 内部时间字段使用 `Date.now()` 数字时间戳；备份清单的导出时间使用 ISO 8601。
- 大于 25 MB 的图片仅显示性能提示，仍会在设备能力允许时尝试处理。
- V1 备份完整性校验侧重 ZIP 结构、清单、数据结构、图片存在性与数量；分批 SHA-256 校验延后评估。
- 后续会接入 `navigator.storage.persist()` / `persisted()`，并在“存储空间”展示保护状态。
- 删除素材将用 Dexie 事务同时删除 Asset、图片与标签关联；不会无提示删除用户创建的未使用标签。
- Service Worker 只能更新和清理应用静态资源缓存，绝不能触碰 IndexedDB 用户数据。

## Phase 3 已实现

- 新增、读取、编辑、删除素材
- 名称、标签、作者、来源和备注的本地搜索
- 类型筛选、特别收藏与一键复制
- 自动创建与复用标签
- 删除素材时，在同一 IndexedDB 事务中删除素材、图片记录和标签关联
